## Why

Se requiere una calculadora que permita realizar operaciones básicas y convertir unidades de masa como kg a g.

## What Changes

- Se agrega una interfaz web para cálculos básicos.
- Se agrega un conversor de masa entre mg, g, kg y t.
- Se mantiene el proyecto como frontend local sin backend adicional.

## Capabilities

### New Capabilities
- `calculator-ui`: captura y resuelve operaciones básicas.
- `mass-converter`: convierte valores entre unidades de masa.

### Modified Capabilities
- None.

## Impact

- `src/App.tsx`, `src/calculator.ts`, `src/styles.css`.
- Archivos de prueba y arranque del proyecto Vite.
