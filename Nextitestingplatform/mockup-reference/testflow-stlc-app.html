HU-001
Como usuario autenticado, quiero transferir fondos entre cuentas propias
Módulo: Transferencias · 5 criterios de aceptación
Generada
Descripción: Como usuario bancario autenticado mediante OAuth 2.0 + MFA, quiero poder realizar transferencias de fondos entre mis cuentas registradas, de manera que pueda gestionar mi liquidez sin necesidad de acudir a un canal presencial.
Criterios de Aceptación:
  • DADO que el usuario está autenticado y tiene saldo disponible, CUANDO ingresa monto válido y cuenta destino propia, ENTONCES la transferencia se procesa en menos de 3 segundos.
  • DADO que el monto excede el saldo disponible, CUANDO intenta confirmar la operación, ENTONCES el sistema retorna error E-4001 con mensaje descriptivo.
  • DADO que la transferencia es exitosa, ENTONCES se genera registro en el módulo COBOL CORECALC y se actualiza saldo en tiempo real.
  • DADO que el servicio ESQL TransfValidation responde RECHAZADO, ENTONCES se registra en el log de auditoría y se notifica al usuario.
  • DADO un fallo de red durante la operación, ENTONCES el sistema implementa rollback y no debita el saldo.
HU-002
Como administrador, quiero configurar reglas de límites de transferencia por perfil de usuario
Módulo: Seguridad · 4 criterios de aceptación
En revisión
Descripción: Como administrador del sistema de seguridad, necesito poder configurar límites diarios, semanales y mensuales de transferencia diferenciados por perfil de usuario (retail, empresarial, VIP), para cumplir con regulaciones de la Superintendencia de Bancos.
  • DADO que el administrador accede al módulo de configuración, CUANDO modifica límite de perfil empresarial, ENTONCES el cambio aplica en el próximo ciclo transaccional (máx. 5 min).
  • DADO que un límite es modificado, ENTONCES el módulo ESQL TransfValidation recibe la nueva regla vía message flow actualizado.
  • DADO que se intenta configurar un límite de $0, ENTONCES el sistema valida y rechaza la configuración con error de negocio.
