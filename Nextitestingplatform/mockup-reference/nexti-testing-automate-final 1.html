# CBS9522 - Consulta de Saldos

## Descripción

Sistema de consulta de saldos bancarios para clientes activos. Permite verificar el saldo disponible y las últimas transacciones de una cuenta.

## Entidades Principales

  • Cliente: Identificado por RUC (10 dígitos)
  • Cuenta: Número de cuenta (10 dígitos)
  • Saldo: Monto disponible (13 enteros, 2 decimales)
  • Estado: Activo (A) o Inactivo (I)

## Flujo Principal

  1. Validación de Cliente: Verifica que el cliente exista en base de datos. Valida que el estado sea 'A' (activo). Si inactivo, retorna error "Cliente inactivo".
  2. Obtención de Saldo: Consulta el saldo actual de la cuenta. Recupera últimas 5 transacciones. Genera log de auditoría.
  3. Presentación de Resultado: Muestra saldo formateado. Lista transacciones recientes. Registra timestamp de consulta.

## Reglas de Negocio

  • Solo clientes activos pueden consultar saldos
  • Máximo 10 consultas por minuto por cliente
  • Todas las consultas generan registro de auditoría
