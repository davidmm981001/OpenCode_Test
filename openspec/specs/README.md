# Especificaciones principales

Esta carpeta es la fuente de verdad del comportamiento actual del sistema.

- Cada capacidad debe vivir en su propia carpeta, por ejemplo `openspec/specs/auth/spec.md`.
- Las delta specs de `openspec/changes/<change>/specs/` se sincronizan aqui al finalizar el cambio.
- No guardar aqui artefactos de implementacion ni notas temporales.
